# 📚 AI 图书馆 · Vault 导览

> 本目录是 **AI 图书馆**（ai-library-obsidian）的知识库本体（vault）。
> 可在 Obsidian 中「打开文件夹作为仓库」指向本目录，即可与 Web UI / 桌面端共用同一份知识。
> 详细设计见项目根 `详细设计文档.md`，开发状态见 `交接文档.md`。

## 这是什么

图书馆式个人知识库：**楼层（来源媒介）→ 房间（语义主题）→ 书架 → 书**。
AI agent 是图书管理员/采购员/档案员/蒸馏师，所有操作都是**建议**，主人确认才生效。

```
books/          ← 正式藏书（按 楼层/房间/书架/书 四级组织）
catalog/        ← 图书卡片（bk_<id>.md，AI 生成的编目信息）
skills/         ← 蒸馏技能（SKILL.md，人审确认后安装）
pending/        ← 采购候选（AI 推荐待主人定夺）
archive/        ← 档案馆（原始副本/蒸馏日志/备份）
profile.md      ← 借书证（兴趣画像，未落盘时为 DB 存储）
```

## 快速上手

1. **逛书架**：打开 `books/`，按 楼层 → 房间 → 书架 浏览；每本书目录下的 `book.md` 是正文。
2. **看编目**：`catalog/bk_<id>.md` 是 AI 生成的图书卡片（一句话简介/摘要/章节/关键概念/标签）。
3. **用 AI**：主入口是 Web UI（`http://127.0.0.1:8800`）或桌面端「AI 图书馆」——扔书入馆、分类建议、问答、采购、蒸馏都在那里。
4. **隐私**：标记为「私密」的书永不发送到任何 API；免费 API 数据可能经手第三方服务商，UI 有明示。

## 硬约束（主人权利）

- **AI 永不删书**：删除仅限主人，且先进档案馆软删除，30 天内可恢复；磁盘原始副本永不被 AI 删除。
- **建议而非覆盖**：分类/蒸馏/采购全部是建议；AI 不覆盖主人手动摆放的内容。
- **操作留痕**：每个 AI 操作写入账本（action ledger），可在管理员页撤销。

## 目录说明

| 路径 | 含义 | 谁在写 |
|---|---|---|
| `books/<楼层>/<房间>/<书架>/<书名>/book.md` | 上架书的正文（不可变副本的清洗版） | 主人确认上架后由系统写入 |
| `catalog/bk_<id>.md` | 图书卡片（书名/简介/摘要/章节/概念/标签） | AI 生成，主人可改 |
| `skills/<slug>/SKILL.md` | 蒸馏技能（cangjie 规范六段式） | AI 蒸馏，主人审阅批准 |
| `pending/` | 采购候选（外部文章/网页快照） | 采购员写入 |
| `archive/` | 原始副本、蒸馏过程日志、备份 | 系统写入，只读 |

> 各层元数据格式见 `schema.md`。
